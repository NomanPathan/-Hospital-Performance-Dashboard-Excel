# 🏥 Hospital Performance Dashboard

## 📊 Excel Data Analytics Project

An interactive **Hospital Performance Dashboard** created using Microsoft Excel to analyze patient admissions, waiting time, satisfaction, demographics, and department-wise patient performance.

---

## 🎯 Project Objective

The objective of this project is to transform hospital patient data into an interactive dashboard that provides a quick and clear overview of hospital performance.

The dashboard helps analyze:

- Patient volume
- Admission status
- Waiting-time performance
- Patient satisfaction
- Gender distribution
- Age-group distribution
- Department-wise patient volume
- Monthly patient activity

## 📈 Dashboard Features

### 🏥 Patient Overview

Displays the total number of patients included in the analysis.

### 🚑 Admission Analysis

Compares admitted and non-admitted patients.

### ⏱️ Waiting-Time Analysis

Shows the percentage of patients attended on time versus delayed.

### 👥 Gender Analysis

Displays the distribution of patients by gender.

### 🎂 Age Group Analysis

Analyzes patients across different age groups.

### 🏨 Department Analysis

Compares patient volume across hospital departments including:

- Cardiology
- Emergency
- Pediatrics
- Dermatology
- Neurology
- Oncology
- Orthopedics

### 📅 Monthly Analysis

Allows users to analyze the dashboard by month using interactive filtering.

## 💡 Business Recommendations

Based on the dashboard analysis:

1. Investigate departments contributing to higher patient waiting times.
2. Monitor peak periods to improve staff and resource planning.
3. Track patient satisfaction alongside waiting time.
4. Monitor departments with consistently high patient volumes.
5. Use monthly analysis to identify changes in patient activity.
